An entry for make.fun's "Famous Last Words at 1 Percent" bounty. The program writes a single line — the funniest possible last words a phone could say as its battery hits 1 percent — to `/output/entry.txt`:

> My last 1%: overheating in your pocket while you googled 'why is my phone so hot.'

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
